## How to Customize

Want to change Site 2's layout to look more like Site 1?

**Before:**
```json
{
  "domain": "mesagaragedoorco.com",
  "hero": "split",
  "services": "list",
  "testimonials": "grid",
  "cta": "card",
  "footer": "compact"
}
```

**After (Edit config/layouts.json):**
```json
{
  "domain": "mesagaragedoorco.com",
  "hero": "banner",        // Changed from "split"
  "services": "featured",  // Changed from "list"
  "testimonials": "carousel", // Changed from "grid"
  "cta": "horizontal",     // Changed from "card"
  "footer": "classic"      // Changed from "compact"
}
```

**Then rebuild:**
```bash
python engine.py build
```

Done! Site now has the new layout combination.
